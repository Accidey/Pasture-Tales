## 牧业模组：隐身玩家与动物逃跑感知 + 守卫者黑名单

### 需求背景（grill-me 讨论后确认）
- 问题：动物逃跑完全不看玩家隐身状态，隐身药水无效。
- 目标行为：
  - 隐身+不疾跑：3 格硬编码距离，30% 概率"闻到气味"触发逃跑，成功时给玩家 info 提示。
  - 隐身+疾跑：不掷骰，必然触发，但触发距离 = 配置 `FLEE_TRIGGER_DISTANCE` 的一半。
  - 正常（不隐身）：原逻辑不变。

### 实现（MobFleeLogic.java）
- 新增常量：`SNIFF_DISTANCE = 3.0`、`SNIFF_CHANCE = 0.3`、`Set<Integer> SNIFF_ROLLED`。
- 新增 `isInvisible(Player)`：`player.hasEffect(MobEffects.INVISIBILITY)`。
- 新增 `effectiveTriggerDist(Player, baseDist)`：隐身+疾跑 → base/2；隐身+不疾跑 → 3.0；否则 base。
- `onEntityTick` 玩家分支重写：
  - 用有效距离扫描。
  - 动物超出有效距离 → 从 `SNIFF_ROLLED` 移除（重置"本次接触"）。
  - `stealthSniff`（隐身+不疾跑）：已在 Set 中则跳过；否则掷 30% 骰，成功 → 发消息 `msg.animalflee.smell` + `processFlee`，失败 → 加入 Set。
  - 非 stealthSniff（含疾跑）：直接 `processFlee`。
- lang 新增：`msg.animalflee.smell`（中英文）。

### 守卫者黑名单（Config.java）
- 需求：守卫者/远古守卫者作为水生敌对生物，不应被牧业模组逃跑系统影响。
- 修改：`BLACKLISTED_MOBS` 默认列表追加 `minecraft:guardian`、`minecraft:elder_guardian`。
- 热重载：`ConfigReloadHandler.onConfigReload` 已调用 `resetBlacklistCache()` + 全量 `stopFlee`，改配置即生效。

### 注意

## 追加：隐身暴露场景扩展（跳跃 + 碰撞）

### 需求（grill-me 确认）
- 隐身玩家 5 格内跳跃 → 与疾跑一样必然被发现（不掷 30% 骰）。
- 隐身玩家与动物发生实体碰撞（AABB 相交）→ 必然触发逃跑。
- 以上仅对隐身玩家生效；不隐身玩家走原有正常逻辑。
- 提示统一：三个暴露场景共用一条消息 `msg.animalflee.smell`。

### 实现（MobFleeLogic.java）
- 新增常量 `JUMP_EXPOSE_DISTANCE = 5.0`。
- 新增 `isJumping(Player)`：`!player.onGround() && player.getDeltaMovement().y > 0.0`。
- 新增 `exposeFlee(ServerPlayer, Mob, double)`：发统一提示 + `processFlee`。
- `onEntityTick` 玩家分支扩展，处理优先级从高到低：
  1. 隐身 + AABB 碰撞（`player.getBoundingBox().inflate(0.1).intersects(mob.getBoundingBox())`）→ `exposeFlee`
  2. 隐身 + 跳跃且 `dist <= 5` → `exposeFlee`
  3. `dist > triggerDist` → 重置 SNIFF_ROLLED 并跳过
  4. 隐身 + 不疾跑 + 不跳跃 → 30% 嗅探掷骰
  5. 其他（不隐身 / 隐身疾跑）→ 直接 `processFlee`
- `exposeFlee` 传 `Math.max(baseDist, dist)`，避免配置触发距离小于跳跃距离时被 `processFlee` 内部拦截。
- lang 文案统一为："动物发现了你，受惊逃走了" / "An animal noticed you and fled"。

### 验证
- `./gradlew build --offline` 成功。
- javap 确认 jar 含 `JUMP_EXPOSE_DISTANCE`、`isJumping`、`exposeFlee`、AABB `intersects`。
- lang JSON 合法，jar 内消息正确。

### 注意
- `isJumping` 用 `onGround + deltaMovement.y` 判断，攀爬/上升气流等边缘情况也可能算"跳跃"（影响很小，可接受）。
- 10 tick 扫描粒度下跳跃状态可能跨 tick，但能捕获到，可接受。

## 追加：修复野生马骑乘/驯服被逃跑系统破坏

### 问题
- 玩家骑上野生马时，玩家与马的 AABB 重叠（距离≈0），触发牧业模组"碰撞暴露"→ `processFlee` 强制 `setNoAi(true)`。
- 马的 `AbstractHorse.aiStep()`（增加驯服度/甩下玩家）被 `setNoAi` 跳过，导致马不把玩家摔下来、也无法被驯服。

### 修复（MobFleeLogic.java）
- 在三个位置加入 `mob.isVehicle()` 拦截（`isVehicle()` = `!passengers.isEmpty()`，即被骑乘）：
  1. `shouldFlee()`：被骑乘 → return false（不触发新逃跑）。
  2. `processFlee()`：被骑乘 → return（双保险）。
  3. `tickFlee()`：正在逃跑时玩家骑上来 → `stopFlee(mob)` 恢复 AI。
- 效果：野生马被骑乘时完全不受逃跑系统影响，原版摔落/驯服 AI 正常；下马后（`isVehicle()` 变 false）恢复逃跑。

### 验证
- `./gradlew build --offline` 成功。
- javap 确认 jar 中 `isVehicle()` 在三个方法中被调用。

### 注意
- 该修复对所有可骑乘动物（马、驴、骡、骆驼、猪等）通用，不仅限于马。

## 追加：马摔下玩家后立即逃跑（无视隐身），驯服/喂食后豁免

### 需求（grill-me 确认）
- 玩家骑乘时走原版 AI（不逃跑）。
- 马把玩家摔下后，2 秒窗口（40 tick）内**无视隐身**，按正常距离立即触发逃跑。
- 豁免：已被驯服（`AbstractHorse.isTamed()`）或已喂食（`HungerSystem.isDomesticated()`）→ 永不逃跑。

### 实现（MobFleeLogic.java）
- 新增 `isExemptFromFlee(Mob)` 统一豁免方法：excluded / maid / domesticated / blacklist / 凯莉猪 / `isVehicle()` / `AbstractHorse.isTamed()`。
- `shouldFlee`、`processFlee`、`tickFlee` 全部改用 `isExemptFromFlee`（原三处分散判断收敛）。
- 新增 NBT 状态追踪：
  - `NBT_RECENTLY_RIDDEN = "AF_RecentlyRidden"`、`NBT_RECENTLY_RIDDEN_TICKS = "AF_RecentlyRiddenTicks"`、`RECENTLY_RIDDEN_TICKS = 40`。
  - `trackRiddenState(Mob)`：每 tick 在 `onEntityTick` Mob 分支调用。被骑乘时置 true；未被骑乘且有标记时累积 ticks，40 tick 后清除；若已豁免则立即清除。
  - `isRecentlyRidden(Mob)`：读标记。
- `onEntityTick` 玩家分支：`isRecentlyRidden(mob)` 时，无视隐身/疾跑/嗅探，若玩家在 `baseDist` 内直接 `processFlee(mob, player, baseDist)`。

### 验证
- `./gradlew build --offline` 成功。
- javap 确认 jar 含 `isExemptFromFlee`（调用 `AbstractHorse.isTamed`）、`trackRiddenState`、`isRecentlyRidden`、`NBT_RECENTLY_RIDDEN*` 常量。

### 注意
- 窗口期内马即使被黑名单豁免也会清除标记（`isExemptFromFlee` 优先），避免无效追踪。
- 2 秒窗口保证玩家有感知空间，窗口结束后恢复正常隐身感知规则。
