## 动物逃跑模组（NeoForge 1.21.1）

- 在 `D:\Games\MOD\牧业` 模组开发包中实现了「动物逃跑」功能。
- 包名：`com.xulai.animalflee`，模组 ID：`animalflee`。
- 功能：被动生物（Animal/AmbientCreature）与水生生物（WaterAnimal/水生 MobCategory）在玩家靠近默认 5 格时逃跑，持续逃跑直到玩家离开。
- 逃跑期间禁用原版 AI（setNoAi(true)），系统强制移动生物到指定位置，含路径检测、卡住自救。
- 配置文件：`fleeTriggerDistance`（默认 5.0）、`passiveMobFlee`（默认 true）、`aquaticMobFlee`（默认 true）、`blacklistedMobs`（默认黑名单：狼/猫/鹦鹉/马/驴/骡/骷髅马/僵尸马/羊驼/行商羊驼/豹猫/海豚/北极熊/蜜蜂/山羊/蝾螈/熊猫/铁傀儡/雪傀儡）。
- 配置注释使用中英文多行块（每个选项用 `#` 分隔的详细注释块）。
- 支持热重载：`ConfigReloadHandler` 监听 `ModConfigEvent.Reloading`，重载时清空黑名单缓存并停止所有正在逃跑的生物。

## 逃跑算法更新（第二次）

- 逃跑方向随机化：不再精确朝玩家反方向跑，而是在「远离玩家的半圆」内随机选角度，模拟动物惊慌失措。
- 逃跑距离扩大：20~35 格（原 10~15）。
- 持续重算：每次 tick 检查玩家是否在逃跑路线 3 格范围内，是则立即重新规划新路线；到达目标点也重算；直到玩家离开触发距离+2格才停止。
- 移动速度微调：0.30 -> 0.32。

## 圈养检测（第三次）

- 新增 `isEnclosed` 检测：以生物为中心，检查东/南/西/北 4 个方向各 4 格内是否有碰撞箱阻挡（栅栏、墙、玻璃等）。
- 若 **≥3 个方向**无法通行，判定为圈养状态，跳过逃跑触发。
- 在三处应用：`shouldFlee`（玩家扫描时过滤）、`processFlee`（触发前二次防线）、`tickFlee`（逃跑中进入圈养区域立即停止）。
- 目的：玩家把动物圈起来喂养时，避免无意义的逃跑路径规划和性能消耗。

## 检测距离与速度调整（第四次）

## JADE 性别不显示 —— 源码级审计（第七次）

- 对照 `D:\Games\MOD\更好的四季\Jade-1.21-neoforge`（即 Modrinth `maven.modrinth:nvQzSEkH:eYz2YBGT` = **Jade 15.10.6+neoforge / 1.21.1**，已用 Modrinth API 核实）逐行审计，确认我们的 API 用法**完全正确**：
  - `IServerDataProvider` 非流式路径仍然有效，Jade 自带的 `NextEntityDropProvider` 就是一模一样的写法。
  - 注册调用与 Jade 自己 `VanillaPlugin` 注册 `MobBreedingProvider` 逐字一致。
  - `HierarchyLookup.get(Cow.class)` 沿父类链收集，注册 `Animal.class` 能命中所有子类。
  - `@WailaPlugin` 无参即可，`FMLLoadCompleteEvent` 在客户端和服务端都会执行 `register()`。
- **关键机制（易踩坑）**：`EntityAccessorImpl.handleRequest` 有 `if (!message.dataProviders().contains(provider)) continue;` —— 服务端只执行客户端请求包里列出的 provider。该列表由**客户端**的 `WailaCommonRegistration.getEntityNBTProviders()` 生成，并用 `entityDataProviders.idMapper()` 的**注册顺序 ID** 过网络。所以客户端和服务端必须各自注册成功且顺序一致，这条链「要么全通、要么全断」。
- **已修的确定 bug**：
  1. `jade.animalflee.gender.unknown` 语言键缺失（会渲染成原始 key）。
  2. `GenderHandler` 用 `LOGGER.debug` —— 正式游戏默认 console level 是 INFO，**日志里永远查不到**，这是之前拿不到线索的直接原因。已改为 INFO。
  3. `AnimalStatusProvider` 加入一次性 INFO 追踪日志（`appendTooltip` / `appendServerData` 各一条），可直接定位断链位置。
- **待用户确认的隐患**：`AnimalFleeModClient` 用 `@Mod(value = AnimalFleeMod.MODID, dist = Dist.CLIENT)`，与主类 `@Mod(AnimalFleeMod.MODID)` **modid 重复**，NeoForge 下不规范。
- **结论**：代码层面无错，剩余失败原因只能是运行时环境，需用户提供 Jade 插件配置界面截图 / `animalflee` 日志。

## 鱼饵通用识别（其他模组种子）（后续）
