## 干草块多蛋孵化（9 格网格）

按 grill-me 确认的设计，实现受精蛋 3×3 网格批量孵化：

- **EggItemUseMixin**：右键干草块顶面，一次把手中受精蛋放入空槽（≥9 放 9 个，≤9 有多少放多少）。每个蛋写入实体 NBT `af_egg_slot`(0~8)，并 `setUnlimitedLifetime`。
- **EggIncubationHandler**：每 tick 把网格蛋拉回槽位坐标（完全固定，水流/碰撞推不动）；9 个蛋独立计时孵化；干草块消失则进度清除、蛋变普通蛋可拾取。
- 槽位偏移 ±0.25，中心 (x+0.5, y+1.0, z+0.5)。
- 拾取保持原行为：禁自动拾取、右键单蛋收进背包、槽位自动空出。
- Jade 天然兼容（每个 ItemEntity 独立显示进度）。
- 开发文档规定不自行构建，仅做代码级自检（所有 API 均在现有代码中出现过）。

## 启动崩溃修复：Mixin 类不能含非私有静态方法

用户启动游戏崩溃，日志关键行：
`Mixin animalflee.mixins.json:EggItemUseMixin ... contains non-private static method isGridEgg(...)`

根因：Mixin 类中 public static 方法会被 Mixin 框架当作待注入目标类的方法，EggItem 没有这些方法 → InvalidMixinException。

修复：
- 新增普通工具类 `logic/EggGridHelper.java`，承载 isGridEgg/getSlot/setSlot/slotX/slotZ/findFreeSlot/collectOccupiedSlots/GRID_SIZE/NBT_SLOT。
- `EggItemUseMixin` 只保留 private `@Inject` 方法。
- `EggIncubationHandler` 改为引用 `EggGridHelper`。

教训：Mixin 类内只写 `@Inject`/`@Redirect` 等注入方法且必须 private；辅助逻辑放普通类。
