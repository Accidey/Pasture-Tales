## 启动崩溃修复：Mixin 类不能含非私有静态方法

用户启动游戏崩溃，日志关键行：
`Mixin animalflee.mixins.json:EggItemUseMixin ... contains non-private static method isGridEgg(...)`

根因：Mixin 类中 public static 方法会被 Mixin 框架当作待注入目标类的方法，EggItem 没有这些方法 → InvalidMixinException。

修复：
- 新增普通工具类 `logic/EggGridHelper.java`，承载 isGridEgg/getSlot/setSlot/slotX/slotZ/findFreeSlot/collectOccupiedSlots/GRID_SIZE/NBT_SLOT。
- `EggItemUseMixin` 只保留 private `@Inject` 方法。
- `EggIncubationHandler` 改为引用 `EggGridHelper`。

教训：Mixin 类内只写 `@Inject`/`@Redirect` 等注入方法且必须 private；辅助逻辑放普通类。
已提交 commit `5fa0431`。

## 海龟豁免修复（2026-10-02 下午追加）

用户问「海龟默认代码怎么处理」。分析原版 `Turtle.java`（720 行）后发现严重问题：

- 原版海龟：`Turtle extends Animal`，`isFood` 只认 `ItemTags.TURTLE_FOOD`（海草/海带）；繁殖走 `TurtleBreedGoal`（喂海草发情 → `setHasEgg` → 回出生沙滩产 `TurtleEggBlock` 方块）；幼崽吃海草 `ageUp` 加速成长；`ageBoundaryReached` 成年掉鳞甲。
- mod 问题链路（与 P0-1 幼崽马同源）：`GrowthHandler` 对所有 Animal 幼崽调用 `GrowthSystem.tickGrowth` → `initGrowth` 把海龟幼崽标记家养 → `HungerSystem.tick` 消耗饥饿 → 但 `AnimalFoods.getSaturation` 对海草返回 0（海草不是作物/种子/肉/鱼）→ `canEat` false → 玩家无法喂食 → 且 `AgeableMobGrowthMixin` 阻止原版自然成长 → **海龟幼崽必然饿死且永远长不大**。

修复（提交 `06b3ac0`）：
1. `GrowthHandler` 增加 `if (animal instanceof Turtle) return;` → 海龟幼崽不再被标记家养。
2. `AgeableMobGrowthMixin` 增加 `if (self instanceof Turtle) { self.setAge(age); return; }` → 海龟幼崽恢复原版自然成长。

复查确认：`HungerSystem.tick` 依赖 `isDomesticated`，海龟不再家养后饥饿不消耗；`PregnancySystem.tryStartPregnancy` 也依赖 `isDomesticated`，海龟不会怀孕。`HungerHandler`/`PregnancyHandler` 仍会 `initHunger`/`tickPregnancy`，但均因非家养而安全返回。编译通过。
