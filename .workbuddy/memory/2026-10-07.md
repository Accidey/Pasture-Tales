## 新功能：受惊扩散（逃跑传染）

先按 grill-me 走了一轮设计审问，锁定的决策：

- **单波扩散**：只有被玩家直接触发（玩家扫描 / 嗅探 / 隐身嗅探 / 跳跃暴露，全都走 `processFlee` 入口）而「开始逃跑」的动物才向外扩散一次；被波及的动物不再继续传播 → 从架构上杜绝级联。
- **参照对象**：被波及者继承源动物的 `AF_FleeSourceUUID`（原触发玩家），复用 `tickFlee` 全套逻辑。
- **对象筛选**：跨物种，但仍走 `shouldFlee` 全套豁免 + 类别判定（牛惊了羊猪鸡都跑，但狼/猫/家养/女仆/DNF 凯莉猪不受影响）。
- **距离**：XZ 水平圆柱，水平距离 ≤ 半径即波及（与现有 `distanceXZ` 一致）。
- **不做视线检测**，纯距离。
- **配置**：只加一项 `panicSpreadRadius`（double，默认 10.0，范围 0.0~64.0，= 0 关闭），运行时实时读取，天然热重载。

## Bug 修复：自然生成幼崽被误标家养

**根因**：`GrowthSystem.initGrowth` 无条件调用 `HungerSystem.setDomesticated(animal)`，而 `tickGrowth` 对所有幼崽都会调 `initGrowth`（原版成长已被 `AgeableMobGrowthMixin` 屏蔽），所以三条幼崽来源（自然生成 / 家养怀孕 / 受精蛋孵化）全被标成家养。

**决策**（用户拍板）：
- 家养只来自「玩家喂食」；**家养后代继承家养**（家养怀孕所生 + 受精蛋孵化）。
- 野生幼崽**不消耗饥饿**、不会被饿死，靠成长系统自行长大（初始饥饿 50%~80% 已达 50% 门槛）。

**改动**：
- `GrowthSystem.initGrowth`：删掉 `HungerSystem.setDomesticated(animal)`。
- `PregnancySystem`：新增 NBT 常量 `NBT_OFFSPRING_DOMESTICATED = "af_offspring_domesticated"`（存在蛋物品 CustomData）；`giveBirth` 里对新生幼崽 `setDomesticated`；`layFertilizedEgg`（旧存档兜底）给蛋打上该标记。
- `ChickenEggLayMixin`：下受精蛋时写入 `af_offspring_domesticated = HungerSystem.isDomesticated(母鸡)`——**注意野生母鸡只要附近有公鸡也会下受精蛋**，所以不能假设蛋一定来自家养母鸡。
- `OviparousLayHandler`：非鸡卵生动物的受精蛋（已要求家养母体）直接打 true。
- `EggIncubationHandler.hatch`：读蛋上的标记，为 true 时把孵出的幼崽标为家养。

**连带影响**（预期）：野生幼崽现在会逃跑（`isExemptFromFlee` 不再豁免）、Jade 不再显示家养、女仆不会喂养野生幼崽。

**未同步**：`开发文档.md` §10.2 仍写着「initGrowth 会 setDomesticated」，Patchouli《幼崽如何长大》条目也仍说「喂食是长起来的唯一途径」——需用户确认后再改。

## 澄清并定案：附近无鱼实体时仍能钓到垃圾/宝藏

用户提问「附近没有鱼的实体钓不上鱼吧，但是可以钓垃圾和宝藏」——核实属实，但**不是一直如此**：

- 重构前的 `FishingRestrictionMixin` 把 `countFishNearby(...) > 0` 放进合法性判定，
  不合法直接 `ci.cancel()` 掉 `catchingFish` → **整杆不咬钩，垃圾/宝藏也拿不到**。
- 遗留的钓鱼重构把鱼实体判定挪到 `FishConsumptionHandler`（钓到后清零 `FISHES` 掉落物），
  门禁漏了，于是垃圾/宝藏漏出来。

用 1.20.1 客户端 jar 内的原版数据核对（结构与 1.21.1 一致）：
`gameplay/fishing` 基础权重 **鱼 85 / 垃圾 10 / 宝藏 5**，宝藏还带 `in_open_water` 条件；
`ItemTags.FISHES` = cod / cooked_cod / salmon / cooked_salmon / pufferfish / tropical_fish，
垃圾与宝藏物品**均不在**该标签里，所以 `containsFish` 为假 → 方法直接 return，掉落物原样进包。

**用户决定：保持现状，只补文档**（不改行为）。净效果 = 85% 空钩 + 15% 垃圾/宝藏。

已同步：`开发文档.md` §1 概述、§14.1、§14.3（新增分支表与要点）；
手册 `fishing/fishing_overview.json` 中英《真实鱼实体》页。
